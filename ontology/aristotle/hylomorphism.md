# Hylomorphism（质料形式论）

## 核心主张

每个自然事物都是 **matter（ὕλη, hyle）** 和 **form（μορφή, morphe）** 的 **compound（σύνολον, synolon）**。Matter 是"它由什么构成"，form 是"它是什么"——使事物成为其所是的组织原则。两者都不独立构成 substance，合在一起才是。

## 解决的问题

Hylomorphism 回应两个前人困局：

1. **Parmenides 的禁令**：Being 不能来自 non-being → 变化不可能。Aristotle 的解法：变化不是"无中生有"，而是 matter 接受新的 form。青铜（matter）被铸成剑（form₁），再被熔铸成盾（form₂）。
2. **Plato 的 Forms 分离问题**：独立存在的 Form 如何作用于具体事物？Aristotle 的解法：form 不在天上，就在事物里面（in rebus）。

## 重要区分

### Form ≠ Shape

Form 不是空间外形，而是功能性的组织原则。双盲试验中的真药和安慰剂 shape 完全一样，但 form 不同（药理活性分子结构 vs 惰性物质），因此是不同的 substance。

### Matter 是相对的

同一个东西在低层级是 form，在高层级变成 matter：

| 层次 | Matter | Form |
|---|---|---|
| 亚原子粒子 → 原子 | 质子、中子、电子 | 原子结构 |
| 原子 → 分子 | 原子 | 键合结构 |
| 分子 → 细胞 | 分子 | 细胞结构 |

没有绝对的 matter。每一层的 matter 都有自己的 matter-form 结构。

### 两种变化

| | Accidental Change | Substantial Change |
|---|---|---|
| 什么变了 | Accident（偶性）| Substantial Form |
| 什么持续 | Substance | Matter |
| 例子 | 苏格拉底晒黑 | 苏格拉底死亡 |
| 生物学例子 | DNA 甲基化改变基因表达 | 蛋白质 prion misfolding |

### Prime Matter（πρώτη ὕλη）

假设的最底层：纯潜能，无任何 form。可能只是 limit concept——逻辑上可定义，经验上不可达。类似物理学的绝对零度。

## Form 的内部张力

Metaphysics VII.8 暗示 form 是 particular（解释个体 identity），VII.13 暗示 form 是 universal（substance 不能是 universal）。这是 Aristotle 体系内部的真实张力，两千年未解。

## 科学例证

- **同分异构体（isomers）**：same matter (C₂H₆O), different form → different substance（乙醇 vs 二甲醚）
- **手性分子（enantiomers）**：结构式相同，3D 空间镜像不同 → form 的差异藏在更深层级
- **蛋白质折叠**：同一氨基酸序列（matter），不同折叠方式（form）→ 正常蛋白 vs prion
- **同位素**：化学 form 相同，核层级 form 不同 → form 的同一性是 inquiry-relative 的

## Form 的不可消除性

Reductionist 试图消除 form，但 form 在每一层因果解释中重新出现：基本粒子的行为仍需"规律"（QCD rules, color charge, confinement）来解释——这些规律就是 form。Reduction 重新定位了 form，但从未消除它。

## 工程类比

- **Matter-form 层级** ↔ abstraction layers：每层的 implementation 是下一层的 API surface
- **DDD**：Entity = identity (form-like) + state (matter-like)；Value Object = 纯 form（由属性完全定义）
- **Docker**：image (form) vs container (form + 运行时资源 = synolon)
- **Form ≠ shape** ↔ interface vs geometry：form 更像 interface

## 思想史位置

```
Parmenides: 变化不可能
    ↓ Aristotle 解决
Hylomorphism（form 在事物中，in rebus）
    ↓ 通过 Aquinas
中世纪经院哲学标准框架（灵魂 = 身体的 form）
    ↓ 17世纪
Descartes/Boyle 机械论挑战（只有广延和运动）
    ↓ 当代
Philosophy of mind 复兴（anti-reductionism）
```
